# 🍺 brew-cli

🚀 A powerful CLI tool to quickly bootstrap backend applications with a clean and scalable structure.

> Inspired by modern tools like `create-react-app`, **brew-cli** helps developers skip repetitive setup and start building instantly.

---

## ⚡ Features

- 🏗️ Generate ready-to-use backend structure
- 📦 Pre-configured project setup
- 🗂️ MVC-based folder structure
- ⚙️ Environment variable support
- 🔐 Authentication setup (JWT) _(planned)_
- 🍃 MongoDB integration _(planned)_
- 🚀 Simple and fast CLI usage

---

## 📦 Installation

No global installation required. Use directly with **npx**:

```bash
npx create-brew-app myApp
```

---

## 🚀 Usage

```bash
npx create-brew-app <project-name>
```

---

## 📌 Example

```bash
npx create-brew-app myBackend
cd myBackend
npm install
npm start
```
